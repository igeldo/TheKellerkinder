# alphaTex – Songs als Text schreiben

alphaTex ist eine Textsprache für Noten und Tabulaturen. Man schreibt einen Song als
einfache Textdatei (`.atex`), und alphaTab macht daraus Noten, Tabs und Klang – ähnlich wie
ein Browser aus HTML eine Webseite macht.

Warum Text statt eines grafischen Editors?

- **Lesbar und vergleichbar:** Zwei Fassungen eines Songs lassen sich Zeile für Zeile vergleichen.
- **Teamfähig:** Jedes Bandmitglied pflegt seine Spur, die Dateien liegen gemeinsam in Git.
- **Prüfbar:** Auch eine KI kann alphaTex schreiben – und man sieht im Text genau, was sie gemacht hat.

Alle Beispiele in dieser Datei wurden mit alphaTab 1.9 geprüft. Zum Ausprobieren in der App
den **alphaTex-Editor** öffnen, auf **Neu** klicken und die Beispiele hineinkopieren.
Das Stück `songs/syntax-beispiele.atex` enthält alle Bausteine zusammen.

---

## 1. Aufbau einer Datei

```
\title "Probe-Riff"        // Kopf: Angaben zum ganzen Song
\artist "Unsere Band"
\tempo 110
.                          // der Punkt trennt Kopf und Noten
\track "E-Gitarre"         // erste Spur
  0.6.4 3.6.4 5.6.2 |
\track "Bass"              // zweite Spur
  0.4.4 3.4.4 5.4.2 |
```

- Befehle beginnen mit einem **Backslash**: `\title`, `\track`, `\tempo`, …
- Der **Punkt** in einer eigenen Zeile beendet den Kopf.
- Jede Spur beginnt mit `\track "Name"`.
- **Kommentare** mit `//` (bis Zeilenende) oder `/* … */` (über mehrere Zeilen).
- Einrückungen und Zeilenumbrüche sind egal; sie dienen nur der Lesbarkeit.

## 2. Spuren einrichten

```
\track "E-Gitarre"
  \staff {tabs}                    // was angezeigt wird
  \instrument distortionguitar     // Klang bei der Wiedergabe
  \tuning (E4 B3 G3 D3 A2 E2)      // Stimmung: von der hohen zur tiefen Saite
  \capo 2                          // Kapodaster im 2. Bund (optional)
```

| Befehl | Bedeutung |
|---|---|
| `\staff {tabs}` | nur Tabulatur |
| `\staff {score tabs}` | Noten und Tabulatur übereinander |
| `\staff {score}` | nur Noten (z. B. für Gesang oder Keyboard) |
| `\instrument …` | Klang, z. B. `distortionguitar`, `overdrivenguitar`, `acousticguitarsteel`, `electricbassfinger`, `acousticgrandpiano`, `voiceoohs`, `percussion` |
| `\tuning (…)` | Stimmung, **immer in Klammern**. Bass: `(G2 D2 A1 E1)`, Drop D: `(E4 B3 G3 D3 A2 D2)` |

### Die Band-Klänge

Für Gitarren, Bass und Schlagzeug bringt TheKellerkinder eigene, hochwertigere Klänge mit.
Einige Varianten liegen in einer anderen **Bank**. Die Bank gibt man in den Spureigenschaften an:

```
\track "Rhythmus" { instrument electricguitarmuted bank 8 }   // Funk-Gitarre
  \staff {tabs}
  \tuning (E4 B3 G3 D3 A2 E2)
```

| Klang | `instrument` | `bank` |
|---|---|---|
| E-Gitarre clean | `electricguitarclean` | – |
| … mit Chorus | `electricguitarclean` | `8` |
| … Clean 2 (heller) | `electricguitarclean` | `12` |
| Jazz-Gitarre | `electricguitarjazz` | – |
| gedämpft (muted) | `electricguitarmuted` | – |
| Funk | `electricguitarmuted` | `8` |
| angezerrt (Overdrive) | `overdrivenguitar` | – |
| Wah-Wah | `overdrivenguitar` | `11` |
| verzerrt (Distortion) | `distortionguitar` | – |
| … mit Feedback | `distortionguitar` | `8` |
| Flageolett | `guitarharmonics` | – |
| Gitarren-Feedback | `guitarharmonics` | `8` |
| Akustik, Stahlsaiten | `acousticguitarsteel` | – |
| Akustik, 12-saitig | `acousticguitarsteel` | `8` |
| Akustik, Nylon | `acousticguitarnylon` | – |
| Kontrabass | `acousticbass` | – |
| E-Bass, Finger | `electricbassfinger` | – |
| E-Bass, Plektrum | `electricbasspick` | – |
| Fretless | `fretlessbass` | – |
| Slap 1 / Slap 2 | `slapbass1` / `slapbass2` | – |
| Schlagzeug | `percussion` | – |

Die Klänge mit `bank` (Chorus, Funk, Wah, Feedback, 12-saitig …) gibt es **nur mit eingeschalteten
Band-Klängen** (Knopf **Band-Klänge** unten in der Wiedergabeleiste); ohne sie bleiben solche Spuren stumm.
Alle anderen General-MIDI-Instrumente (Klavier, Orgel, Gesang, Bläser …) gibt es mit den
Standardklängen, aber **nur in Bank 0**. Eine Bank, die es für ein Instrument nicht gibt, bleibt stumm.

**Klang innerhalb einer Spur wechseln:** `{instrument …}` hinter der Dauer einer Note bzw. eines Akkords
wechselt ab dieser Stelle den Klang, die Bank bleibt die der Spur:

```
(0.6 2.5 2.4).4{instrument overdrivenguitar} (3.6 5.5 5.4) (5.6 7.5 7.4) |
```

**Höchstens 7 Spuren plus Schlagzeug.** Jede Spur belegt zwei der 16 Wiedergabekanäle. Weitere
Spuren werden zwar angezeigt, bleiben aber stumm. Wer mehr Klänge braucht, wechselt sie innerhalb
einer Spur (siehe oben). Alle Klänge zum Anhören: Song **`klang-demo.atex`**.

## 3. Eine Note: Bund.Saite

Eine Gitarrennote schreibt man als **`Bund.Saite`**:

```
Saite 1  e |----------------    ← höchste Saite
Saite 2  H |----------------
Saite 3  G |----------------
Saite 4  D |----------------
Saite 5  A |---3------------    ← 3.5 = 3. Bund auf der A-Saite
Saite 6  E |-0--------------    ← 0.6 = leere tiefe E-Saite
```

- `0.6` – leere tiefe E-Saite
- `3.5` – 3. Bund auf der A-Saite
- `12.1` – 12. Bund auf der hohen e-Saite

Beim **Bass** gilt dasselbe: Saite 1 ist die G-Saite, Saite 4 die tiefe E-Saite.

Für Instrumente ohne Bünde (Gesang, Keyboard) schreibt man **Notennamen**: `C4`, `D#4`, `Bb3`.

```
\track "Gesang"
  \staff {score}
  \instrument voiceoohs
  C4.4 D4.4 E4.2 |
```

## 4. Wie lang? Dauern, Pausen, Rhythmus

Die Dauer hängt man mit einem weiteren Punkt an:

| Schreibweise | Dauer |
|---|---|
| `3.5.1` | ganze Note |
| `3.5.2` | halbe Note |
| `3.5.4` | Viertel |
| `3.5.8` | Achtel |
| `3.5.16` | Sechzehntel |

```
3.5.4 5.5.8 7.5.8 3.5.2 |
```

**Dauer für mehrere Noten vorgeben.** Mit `:8` gelten alle folgenden Noten als Achtel, bis eine neue
Angabe kommt. Das spart viel Schreibarbeit:

```
:8 3.5 5.5 7.5 5.5 :4 3.5 0.6 |
```

**Weitere Rhythmus-Bausteine:**

| Baustein | Beispiel | Bedeutung |
|---|---|---|
| Pause | `r.4` | Viertelpause |
| Punktierung | `3.5.4{d}` | punktierte Viertel (1½ Schläge) |
| Triole | `3.5.8{tu 3} 5.5.8{tu 3} 7.5.8{tu 3}` | drei Achtel in der Zeit von zwei |
| Haltebogen | `3.5.2 -.5.2` | Note klingt in die nächste hinein (`-` statt Bund) |
| Wiederholung | `3.5.8 * 8` | dieselbe Note achtmal |
| Taktstrich | `\|` | beendet einen Takt |

Jeder Takt muss voll sein: In 4/4 also z. B. vier Viertel, acht Achtel oder eine Halbe und zwei Viertel.

## 5. Akkorde

Mehrere Noten, die gleichzeitig klingen, stehen in **runden Klammern**. Die Dauer kommt hinter die Klammer:

```
(0.6 2.5 2.4).4                  // E5-Powerchord als Viertel
(0.6 2.5 2.4 1.3 0.2 0.1).1      // offener E-Dur-Akkord als ganze Note
```

Mit einem Akkordnamen darüber:

```
(0.6 2.5 2.4 1.3 0.2 0.1).1{ch "E"}
```

## 6. Spieltechniken

Spieltechniken stehen in **geschweiften Klammern**. Dabei gibt es eine wichtige Regel:

- Techniken, die **eine Note** betreffen, stehen **direkt hinter der Note** – vor der Dauer.
- Angaben, die **den ganzen Schlag** betreffen, stehen **hinter der Dauer**.

```
5.3{h}.4          // Hammer-on: gehört zur Note → vor der Dauer
3.5.4{d}          // Punktierung: gehört zum Schlag → hinter der Dauer
```

Am einfachsten wird es mit vorgegebener Dauer (`:4`), dann entfällt die Frage:

```
:4 5.3{h} 7.3 7.3{sl} 9.3 |
```

### Techniken an der Note

| Kürzel | Technik | Beispiel |
|---|---|---|
| `h` | Hammer-on / Pull-off (zur nächsten Note auf derselben Saite) | `:8 5.3{h} 7.3` |
| `sl` | Slide zur nächsten Note | `:4 7.3{sl} 9.3` |
| `sod` / `sou` | Slide aus der Note heraus nach unten / oben | `:2 7.3{sod}` |
| `sib` / `sia` | Slide von unten / oben in die Note hinein | `:2 7.3{sib}` |
| `b (0 4)` | Bending um einen Ganzton (4 = Ganzton, 2 = Halbton) | `:2 7.3{b (0 4)}` |
| `b (0 4 0)` | Bending hoch und wieder zurück | `:2 7.3{b (0 4 0)}` |
| `v` / `vw` | Vibrato / weites Vibrato | `:2 7.3{v}` |
| `pm` | Palm Mute (Abdämpfen mit dem Handballen) | `:8 0.6{pm}` |
| `x` | Dead Note (gedämpfter Anschlag ohne Ton) | `:8 0.6{x}` |
| `lr` | Let Ring (ausklingen lassen) | `:2 0.6{lr}` |
| `nh` | Flageolett (natürlich) | `:4 12.1{nh}` |
| `st` | Staccato | `:4 3.5{st}` |
| `ac` | Akzent | `:4 3.5{ac}` |

Mehrere Techniken lassen sich kombinieren: `7.3{b (0 4) v}` ist ein Bending mit Vibrato.

### Angaben am Schlag

| Kürzel | Bedeutung | Beispiel |
|---|---|---|
| `d` | punktiert | `3.5.4{d}` |
| `tu 3` | Triole | `3.5.8{tu 3}` |
| `dy …` | Lautstärke: `pp`, `p`, `mp`, `mf`, `f`, `ff` | `3.5.4{dy ff}` |
| `ch "…"` | Akkordname | `(0.6 2.5 2.4).4{ch "E5"}` |
| `sd` / `su` | Abschlag / Aufschlag | `(0.6 2.5 2.4).4{sd}` |
| `txt "…"` | Text über der Note | `3.5.1{txt "langsam"}` |

## 7. Takte, Abschnitte, Wiederholungen

Angaben, die **für einen Takt** gelten, stehen **am Anfang des Takts**, also direkt nach dem
vorherigen Taktstrich:

```
\section "Intro"            // Abschnittsname über dem Takt
\ro                         // Wiederholung beginnt
:4 0.6 0.6 3.6 5.6 |
\rc 2                       // Wiederholung endet: insgesamt 2-mal spielen
:4 0.6 0.6 5.6 3.6 |
\section "Strophe"
:1 0.6 |
```

| Befehl | Bedeutung |
|---|---|
| `\section "Refrain"` | Abschnitt mit Namen |
| `\ro` | Wiederholungszeichen auf (repeat open) |
| `\rc 2` | Wiederholungszeichen zu, Anzahl der Durchgänge (repeat close) |
| `\ae 1` / `\ae 2` | erste / zweite Klammer (Volta) |
| `\ts (3 4)` | Taktart 3/4 (gilt ab diesem Takt) |
| `\tempo 140` | neues Tempo ab diesem Takt |
| `\tf triplet8th` | Shuffle / Triolen-Feeling |

Wiederholung mit erster und zweiter Klammer:

```
\ro 3.5.1 |
\ae 1 \rc 2 5.5.1 |
\ae 2 7.5.1 |
```

**Hinweis für mehrere Spuren:** Abschnitte, Wiederholungen, Taktart und Tempo gelten für alle Spuren.
Man schreibt sie nur in der **ersten Spur**. Alle Spuren müssen gleich viele Takte haben.

## 8. Schlagzeug

Beim Schlagzeug steht statt Bund und Saite die **Nummer des Instruments** (General MIDI):

```
\track "Schlagzeug"
  \instrument percussion
  \clef neutral
  :8 (36 42) (42) (38 42) (42) (36 42) (36 42) (38 42) (42) |
```

| Nummer | Instrument | Nummer | Instrument |
|---|---|---|---|
| 36 | Bassdrum | 46 | Hi-Hat offen |
| 38 | Snare | 44 | Hi-Hat mit Fuß |
| 37 | Rimshot / Side Stick | 49 | Crash-Becken |
| 42 | Hi-Hat geschlossen | 51 | Ride-Becken |
| 45 | Tom tief | 48 | Tom hoch |

Jeder Schlag steht **in Klammern** – auch ein einzelner: `(42)`. Gleichzeitige Schläge
kommen in dieselbe Klammer: `(36 42)` ist Bassdrum und Hi-Hat zusammen.

## 9. Häufige Fehler

| Fehler | Was passiert | Richtig |
|---|---|---|
| `\tuning E4 B3 G3 D3 A2 E2` direkt vor einem Akkord | der Akkord wird als Teil der Stimmung gelesen | `\tuning (E4 B3 G3 D3 A2 E2)` |
| `42.8` beim Schlagzeug | wird als „Bund 42, Saite 8“ gelesen | `(42).8` |
| `5.3.4{h}` | `h` gehört zur Note, nicht zum Schlag → Fehlermeldung | `5.3{h}.4` |
| `\rc 2` am Ende eines Takts | beginnt einen neuen Takt | `\rc 2` an den **Anfang** des letzten Takts der Wiederholung |
| Takt zu kurz oder zu lang | Noten verrutschen in den nächsten Takt | Dauern nachzählen |
| Tippfehler im Instrumentnamen, z. B. `\instrument distortiongitar` | **keine** Fehlermeldung, die Spur klingt einfach wie ein Klavier | Namen prüfen, wenn der Klang nicht stimmt |

Der Editor der App zeigt Fehler mit Zeile und Spalte an. Ein Klick auf die Meldung springt zur Stelle.
